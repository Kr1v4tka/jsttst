## Быстрый старт

### Вариант 1 — встроенный сервер (рекомендуется)

```bash
git clone https://github.com/Kr1v4tka/jsttst.git
cd jsttst
npm run dev
```

Откройте <http://127.0.0.1:8080>.

Свой порт:

```bash
npm run dev -- 3000
# или
PORT=3000 npm run dev
```

### Вариант 2 — любой статический сервер

```bash
python -m http.server 8080        # Python 3
npx serve .                       # Node.js
php -S localhost:8080             # PHP
```

### ⚠️ Почему нельзя открывать через `file://`

Проект использует **ES-модули** (`<script type="module">`). Браузеры применяют
к ним политику CORS даже для локальных файлов, поэтому при двойном клике по
`index.html` вы увидите ошибки вида:

```
Access to script at 'file:///.../js/app.js' from origin 'null' has been blocked by CORS policy
```

Это не баг проекта — так работают все современные браузеры. Нужен любой
HTTP-сервер из списка выше.

## Физическая песочница

Полноценный 2D-движок твёрдых тел, написанный с нуля.

### Возможности

- **Формы** — круги и выпуклые многоугольники (прямоугольники, N-угольники)
- **Столкновения** — SAT с клиппингом опорной грани, до двух точек контакта
- **Решатель** — sequential impulses с накоплением импульсов и warm starting
- **Соединения** — DistanceJoint (верёвка/пружина, регулируемая жёсткость)
- **Захват мышью** — MouseJoint с ограничением силы
- **Сон тел** — тела засыпают, когда скорость падает ниже порога
- **Частицы** — пул на 2400 частиц, эффекты ударов и разрушения
- **Фиксированный шаг** — 1/120 с, физика не зависит от FPS

### Управление

| Действие | Как |
|---|---|
| Выделение / перетаскивание | `V` или ЛКМ по телу |
| Создание тела | `B` или ЛКМ по пустому месту |
| Удаление | `E`, ПКМ или инструмент «Удалить» |
| Заморозить / разморозить | `F` |
| Соединить два тела | `J`, затем клик по двум телам |
| Пауза | `Пробел` |
| Отменить выбор | `Esc` |

### Сцены-заготовки

Демо-сцена, Башня, Дождь, Маятник, Наклонная плоскость, Люлька Ньютона, Полигоны.

### Настройки

Гравитация, упругость, трение, скорость времени (0.1×–2×), тема сцены
(Полночь / Графит / Бумага), сетка, векторы скорости, точки контакта, тени,
частицы, сон тел.

### Отладочный доступ

В консоли браузера доступен объект `window.__sandbox`:

```js
__sandbox.world.bodies.length        // сколько тел
__sandbox.loadPreset('cradle')       // загрузить сцену
__sandbox.world.setGravity(-400)     // инвертировать гравитацию
__sandbox.renderer.options.showContacts = true
```

## Стерео-оценщик глубины

Восстанавливает карту глубины из двух фотографий одной сцены, снятых с
горизонтальным смещением.

### Возможности

- **Метрики сопоставления** — SAD, Census Transform, ZNCC
- **Субпиксельное уточнение** — параболическая интерполяция
- **Фильтрация** — LR-консистентность, медианный фильтр, удаление спеклов, заполнение дыр
- **Визуализация** — карта диспаратности (Turbo / Viridis / Grayscale), облако точек, 3D-меш
- **Экспорт** — PLY (облако точек с цветами), OBJ (модель с UV), PNG (карты)
- **Демо-генератор** — синтетическая стереопара с известной глубиной

### Интерфейс

Оформлен в стиле Windows 98. Пять групп настроек в боковой панели:
изображения, алгоритм, фильтрация, визуализация, экспорт.

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl` + `Enter` | Вычислить глубину |
| `1` … `4` | Переключить вкладку |
| `Esc` | Закрыть диалог |

### Терминология

**Диспаратность** — горизонтальный сдвиг пикселя между левым и правым кадром.
Чем ближе объект, тем больше сдвиг. Глубина вычисляется как `Z = f·B / d`,
где `f` — фокусное расстояние, `B` — база между камерами, `d` — диспаратность.

Конвенция в коде: `right[x] = left[x + d]`, то есть диспаратность показывает,
насколько пиксель в **правом** кадре находится правее. Значение `-1`
зарезервировано под «нет данных» (`INVALID`).

## Архитектура

### Физический движок

Движок намеренно **не зависит от DOM** — это позволяет запускать его в Node.js
и покрывать тестами без эмуляции браузера.

```
advance(dt)
  └─ аккумулятор → step(1/120) × N
       ├─ 1. integrateVelocity      сила + гравитация + демпфирование
       ├─ 2. broadphase             spatial hash → пары-кандидаты
       ├─ 3. narrow phase           collide() → Contact[]
       ├─ 4. joint.prepare()        эффективные массы соединений
       ├─ 5. warmStart + solveVelocity
       ├─ 6. integratePosition
       ├─ 7. solvePosition          коррекция по локальным якорям
       ├─ 8. resolveBounds          отскок от стен
       ├─ 9. storeImpulses          кэш для следующего шага
       └─ 10. updateSleep           усыпление медленных тел
```

**Почему фиксированный шаг.** Переменный `dt` делает физику недетерминированной:
при просадке FPS тела начинают «проваливаться» и взрываться. Аккумулятор
гарантирует одинаковое поведение на 30 и 144 Гц.

**Почему warm starting.** Импульсы прошлого шага применяются повторно как
начальное приближение. Без этого стопки из 5+ коробок «дрожат» и расходятся.

**Почему локальные якоря.** Позиционная коррекция хранит точки контакта в
локальных координатах тела, поэтому остаётся корректной даже если тело
повернулось за шаг.

### Стереозрение

```
стереопара
  └─ toGrayscale
       └─ [Census Transform]         ← только для метрики census
            └─ computeDisparity      SAD / Census / ZNCC + субпиксель
                 ├─ leftRightCheck   отбраковка неоднозначных
                 ├─ medianFilter     3×3
                 ├─ removeSpeckles   связные области < N пикселей
                 └─ fillHoles        заполнение пропусков
                      ├─ colorizeDisparity → PNG
                      ├─ buildPointCloud  → PLY / Three.js
                      └─ toOBJ            → 3D-меш
```

Порог уникальности отбрасывает пиксели, где лучший вариант сопоставления
недостаточно превосходит второй по качеству — типичная причина для
повторяющихся текстур (заборы, плитка, трава).

## Решение проблем

### «Песочница не работает / пустой экран»

Открыт `file://`. Запустите `npm run dev` и откройте `http://127.0.0.1:8080`.

### «Порт занят»

```bash
npm run dev -- 8081
```

### «Низкий FPS»

- Уменьшите число тел кнопкой «Очистить»
- Отключите «Частицы» и «Тени» в разделе «Вид»
- Уменьшите «Скорость времени»
- Проверьте значение «Шаг» в статистике: если оно > 8 ms, движок упирается в CPU

### «Стерео-карта выглядит шумной»

- Увеличьте «Размер блока» (7 → 11)
- Включите «LR-консистентность»
- Включите «Удаление спеклов»
- Смените метрику на **Census** или **ZNCC**, если кадры сняты с разной экспозицией

### «3D-вкладка пустая»

Вкладки «Точки» и «3D Модель» требуют библиотеку Three.js, которая
загружается с `unpkg.com` через import map. Нужен доступ в интернет.
