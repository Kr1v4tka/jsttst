## 🎮 Доступные симуляции

### 1. Песочница с физикой 🔬
Интерактивная физическая песочница с поддержкой:
- Гравитации и столкновений (SAT/AABB)
- Вращения объектов и угловой динамики
- Системы частиц для визуальных эффектов
- Пространственной сетки для оптимизации коллизий
- Сна объектов для производительности
- Соединений между объектами (Joint)

**Путь:** `simulations/sandbox/index.html`

**Управление:**
- **ЛКМ** — создать объект / перетащить
- **ПКМ** — удалить объект
- **Перетаскивание** — перемещение объектов
- **Инструмент "Соединение"** — клик-клик для связи двух объектов

**Инструменты:**
- 👆 Выделение — перетаскивание объектов
- ➕ Создать — создание объектов кликом
- 💥 Удалить — удаление объектов кликом
- ❄️ Заморозить — фиксация объектов
- 🔗 Соединение — связь объектов

**Параметры физики:**
- Гравитация (-20 до 20 м/с²)
- Упругость (0-1)
- Трение
- Масштаб времени (0.1x-2x)

### 2. Стерео-глубина (Stereo Depth Estimator)
Вычисление карты глубины из стереопары изображений:
- Алгоритмы SAD Block Matching и Census Transform
- Субпиксельное уточнение диспаратности
- LR-консистентность и медианная фильтрация
- 3D визуализация point cloud через Three.js
- Экспорт в PLY, OBJ форматы

**Путь:** `demo/Stereo.html`

## ✅ Быстрый старт (3 способа)

### Способ 1: Python HTTP Server (Рекомендуется)

```bash
# Шаг 1: Откройте терминал и перейдите в папку с песочницей
cd /workspace/simulations/sandbox

# Шаг 2: Запустите локальный сервер
python3 -m http.server 8080

# Шаг 3: Откройте браузер и перейдите по адресу
http://localhost:8080
```

**Преимущества:**
- ✅ Нет ограничений безопасности браузера
- ✅ Корректная загрузка всех JS-модулей
- ✅ Работает на любой ОС (Windows, macOS, Linux)

---

### Способ 2: Node.js http-server

```bash
# Шаг 1: Установите http-server (если не установлен)
npm install -g http-server

# Шаг 2: Перейдите в папку с песочницей
cd /workspace/simulations/sandbox

# Шаг 3: Запустите сервер
http-server -p 8080

# Шаг 4: Откройте в браузере
http://localhost:8080
```

---

### Способ 3: Прямое открытие файла (Не рекомендуется)

```bash
# Просто откройте файл в браузере
# Windows:
start simulations/sandbox/index.html

# macOS:
open simulations/sandbox/index.html

# Linux:
xdg-open simulations/sandbox/index.html
```

⚠️ **Внимание:** При этом способе могут быть ограничения безопасности CORS, которые заблокируют загрузку некоторых ресурсов.

## 🐛 Решение проблем

### Проблема: "Песочница не работает / пустой экран"

**Причина 1:** Браузер блокирует загрузку локальных файлов
- **Решение:** Используйте локальный сервер (Способ 1 или 2)

**Причина 2:** Неправильный путь к файлам
- **Решение:** Убедитесь, что вы в папке `simulations/sandbox/`

**Причина 3:** Порт 8080 занят
- **Решение:** Используйте другой порт:
  ```bash
  python3 -m http.server 8000
  # Затем откройте http://localhost:8000
  ```

### Проблема: "Объекты не создаются"

**Проверьте:**
1. Консоль браузера (F12) на наличие ошибок
2. Что JavaScript включён в браузере
3. Что файлы `physics.js` и `main.js` загружаются (вкладка Network в DevTools)

### Проблема: "Низкий FPS / лаги"

**Решение:**
1. Уменьшите количество объектов
2. Отключите эффекты частиц в настройках
3. Отключите "Сон объектов" если он включён

## 📊 Характеристики физического движка

- **Интеграция**: Semi-implicit Euler
- **Коллизии**: SAT (Separating Axis Theorem), AABB
- **Разрешение**: Position Based Dynamics (PBD)
- **Оптимизация**: Uniform Spatial Grid
- **Сон объектов**: Порог скорости 0.1 м/с
- **Частицы**: Система с временем жизни
- **Объекты**: Circle, Rectangle, Polygon
- **Соединения**: Spring Joint с регулировкой жёсткости
