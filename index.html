Под капотом

Как это устроено

Физический движок

  • Интегратор — полунеявный Эйлер на фиксированном шаге 1/120 с
  • Широкая фаза — uniform spatial hash по AABB
  • Узкая фаза — SAT для полигонов с клиппингом опорной грани
  • Решатель — sequential impulses с накоплением и warm starting
  • Коррекция — позиционная, по локальным якорям контакта
  • Оптимизация — сон тел и пул частиц

Стереозрение

  • Метрики — SAD, Census Transform, ZNCC
  • Уточнение — параболическая интерполяция диспаратности
  • Отбраковка — порог уникальности и LR-консистентность
  • Постобработка — медиана, удаление спеклов, заполнение дыр
  • 3D — облако точек и меш на Three.js
  • Экспорт — PLY, OBJ, PNG-карты

Инженерия

  • Модули — нативные ES-модули, без сборщика
  • Тесты — node --test, 45 проверок
  • Движок — не зависит от DOM, тестируется в Node.js
  • Доступность — клавиатура, ARIA, reduced-motion
  • Адаптив — тач и мышь через Pointer Events
  • Сервер — встроенный статический сервер на Node.js

Быстрый старт

Запуск за одну минуту

1

Клонируйте репозиторий

git clone https://github.com/Kr1v4tka/jsttst.git
cd jsttst
2

Запустите сервер

npm run dev

Без npm: python -m http.server 8080

3

Откройте в браузере

http://localhost:8080

Открытие через file:// не сработает: браузер заблокирует ES-модули из-за CORS.
