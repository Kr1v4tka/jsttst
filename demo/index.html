Что делает программа?

Вычисляет карту глубины из двух фотографий одной сцены (стереопары), снятых с небольшим горизонтальным смещением. По карте глубины строятся облако точек и 3D-модель.

1. Загрузка изображений

  • Левое / Правое — нажмите на область или перетащите файл. Левое фото снято левее.
  • Сгенерировать демо — создаёт тестовую стереопару с объектами на разной глубине.

2. Алгоритм

  • SAD — сумма абсолютных разностей. Быстрый, хорошо работает на текстурированных сценах.
  • Census — сравнение структуры окрестности. Устойчив к перепадам освещения, медленнее.
  • ZNCC — нормированная корреляция. Наиболее устойчив к изменению яркости и контраста.
  • Макс. диспаратность — максимальный горизонтальный сдвиг в пикселях.
  • Размер блока — окно сопоставления (нечётное). Больше блок — меньше шума, хуже детали.
  • Масштаб — 1/1 полное разрешение (медленно), 1/4 рекомендуется.
  • Порог уникальности — насколько лучший вариант должен превосходить второй.

3. Фильтрация

  • Субпиксельное уточнение — параболическая интерполяция, убирает «ступеньки».
  • LR-консистентность — отбрасывает пиксели, не подтверждённые обратным поиском.
  • Медианный фильтр — убирает одиночные выбросы.
  • Удаление спеклов — убирает мелкие изолированные островки.
  • Заполнять дыры — заполняет оставшиеся пропуски медианой соседей.

4. Визуализация

  • Управление 3D — ЛКМ/палец: вращение, ПКМ/два пальца: перемещение, колесо/щипок: масштаб.
  • Размер точки — для облака точек.
  • Wireframe — каркасный вид 3D-модели.

5. Экспорт

  • PLY — облако точек с цветами (CloudCompare, MeshLab, Blender).
  • OBJ — полигональная модель с UV-координатами.
  • Глубина / Дисп. — карты в PNG.

Горячие клавиши

  • Ctrl+Enter — вычислить, 1…4 — переключить вкладку, Esc — закрыть диалог.
